
# TaskFlow – JavaScript Task Management App

## Overview

TaskFlow is a responsive task management web application built with HTML, CSS, and JavaScript.

It helps users organize daily responsibilities by adding, viewing, editing, deleting, filtering, and completing tasks.

The application validates task descriptions and uses the browser's localStorage to keep tasks after the page is closed or refreshed.
